# Test data

The portraits are public domain NASA photos, downscaled to 500 pixels wide:

| File | Source |
| --- | --- |
| `sally_ride_1979.jpg` | [Sally Ride 1979](https://commons.wikimedia.org/wiki/File:Sally_Ride_1979.jpg) |
| `sally_ride_1984.jpg` | [Sally Ride (1984)](https://commons.wikimedia.org/wiki/File:Sally_Ride_(1984).jpg) |
| `chris_hadfield_2011.jpg` | [Chris Hadfield 2011](https://commons.wikimedia.org/wiki/File:Chris_Hadfield_2011.jpg) |

Two photos of the same person, taken five years apart, check that face
matching works across real photos, and a third person checks that it doesn't
match strangers.

`feed.xml` is a small made-up RSS feed for the news tests.
